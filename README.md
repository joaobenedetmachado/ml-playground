# Machine Learning Studies

This repository organizes my Machine Learning studies with a focus on practical applications. The goal is to learn how to solve real-world problems efficiently, prioritizing what produces the most impact.

## Study Structure

### 1. Data Understanding & Preparation
- Data exploration using pandas, matplotlib, and seaborn  
- Cleaning: handling missing values, duplicates, and outliers  
- Normalization and standardization  
- Encoding categorical variables (one-hot, label encoding)  
- Train/validation/test split  

### 2. Core Models
- **Logistic Regression** — simple classification  
- **Random Forest** — robust, good for tabular data  
- **XGBoost / LightGBM** — great balance of performance and interpretability  

### 3. Model Evaluation
- Metrics: accuracy, precision, recall, F1-score, ROC-AUC  
- Choose metrics according to the problem type  

### 4. Avoiding Overfitting
- Techniques: regularization, cross-validation, early stopping  
- Focus: train well and generalize to unseen data  

### 5. Hyperparameter Tuning
- Hyperparameters guide model training  
- Tools: GridSearchCV, RandomizedSearchCV  

### 6. Text & Basic NLP
- Converting text into numbers: TF-IDF, word embeddings, BERT embeddings  
- Applications: reviews, emails, news, chat data  

### 7. Practical ML Cycle
1. Collect and prepare data  
2. Split into train/validation/test sets  
3. Train the model  
4. Evaluate and adjust  
5. Simple deployment using pickle/joblib or API with FastAPI/Flask  

### 8. What to Avoid Initially
- Deep neural networks without practical need  
- Very new models without mastering the core ones  
- Implementing algorithms from scratch  
- Advanced MLOps frameworks at the start  

## Getting Started
Clone the repository and follow the notebooks and scripts in the `/notebooks` folder for exercises and mini-projects.
