Overfitting → rede gigante decora números, mas erra no teste.

Regularization → força simplicidade, evita que o modelo decore.

Cross-Validation → avalia de forma mais justa, evita “azar” numa divisão.

Early Stopping → interrompe treino quando começa a piorar no teste.

Regressão Logística → baseline simples e rápido, bom ponto de partida.
